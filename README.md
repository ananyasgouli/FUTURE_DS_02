# Future DS 02 – Customer Retention & Churn Analysis

## 📊 Project Overview

This project was completed as part of the **Future Interns Data Science & Analytics Task 2**.

The objective of this project is to analyze customer churn and identify the key factors that influence customer retention. The analysis was performed using **Power BI** with the Telco Customer Churn dataset.

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- CSV Dataset

## 📁 Project Files

- `Customer_Retention_Churn_Analysis.pbix` – Power BI dashboard
- `WA_Fn-UseC_-Telco-Customer-Churn.csv` – Dataset used for analysis
- `Customer_Churn_Dashboard.png` – Final dashboard screenshot

## 📈 Key Metrics

- **Total Customers:** 7k
- **Churned Customers:** 2k
- **Overall Churn Rate:** 26.5%
- **Monthly Revenue:** Approximately $456.1K

## 🔍 Analysis Performed

The dashboard analyzes customer churn based on:

- Contract type
- Internet service
- Payment method
- Customer tenure
- Overall churn distribution

## 💡 Key Insights

- Month-to-month customers represent an important churn-risk segment.
- Newer customers have higher retention risk compared with long-tenure customers.
- Churn varies across different internet service and payment method segments.
- Contract type is an important factor influencing customer retention.

## 🎯 Recommendations

- Introduce targeted retention offers for month-to-month customers.
- Improve onboarding and engagement for new customers.
- Identify high-risk customer segments and provide personalized offers.
- Encourage customers to move toward longer-term contracts.
- Monitor payment and service-related churn patterns regularly.

## 📷 Dashboard Preview

The final Power BI dashboard provides an interactive view of customer churn and retention patterns.
